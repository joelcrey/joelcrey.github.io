These are notes explaining the algorithm of Han and Monsky [HM93] to compute the Hilbert–Kunz function and the F-signature function of any diagonal hypersurface $x_1^{d_1}+\dots+x_n^{d_n}$, in any characteristic, together with the extension of Chiang and Hung [CH98] to sums of monomials in disjoint variables.

The notes are summarised in a series of posts, with SageMath cells you can run in the browser:

{% include series-nav.html series="han-monsky" %}

To run the code on your own computer, download `hilbert_kunz.py` and the notebooks into the same folder, start SageMath there, and type `load("hilbert_kunz.py")`.

- [HM93] C. Han, P. Monsky, *Some surprising Hilbert–Kunz functions*, Math. Z. 214 (1993), 119–135, [doi](https://doi.org/10.1007/BF02572395).
- [CH98] L. Chiang, Y.-C. Hung, *On Hilbert–Kunz functions of some hypersurfaces*, J. Algebra 199 (1998), 499–527, [doi](https://doi.org/10.1006/jabr.1997.7206).

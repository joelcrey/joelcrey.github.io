The [Han–Monsky algorithm](han-monsky-3-the-algorithm.html) computes $\operatorname{HK}_e(R,I)$ for every monomial ideal $I=(x_1^{a_1},\dots,x_n^{a_n})$, not just the maximal ideal. This post shows that this is enough to compute F-signature functions too. It is one way of approaching this computation, probably complementary to the techniques of [CSTZ24]: in op. cit., some formulas are attained which I am not sure can be obtained directly through Han–Monsky.

As always, run the first cell before the others.


## F-signatures as Hilbert–Kunz functions

**Proposition** (Huneke–Leuschke [HL04]). Let $(R,\mathfrak m,k)$ be an F-finite Gorenstein local ring of dimension $d$ and characteristic $p$, with $k=k^p$. Let $I$ be an ideal generated by a system of parameters, and $u\in R$ a socle element of $R/I$, so that $(I:\mathfrak m)=I+(u)$. Then, with $q=p^e$,
$$\operatorname{FS}_e(R)=\ell\big(R/I^{[q]}\big)-\ell\big(R/(I+(u))^{[q]}\big)=\ell(R/I)\,q^d-\operatorname{HK}_e\big(R,I+(u)\big).$$
If $I$ is a minimal reduction of $\mathfrak m$, then $\ell(R/I)=e(R)$, and so $\operatorname{FS}_e(R)+\operatorname{HK}_e(R,I+(u))=e(R)\,q^d$.

For a diagonal hypersurface, there is an obvious choice:

**Lemma.** Let $f=x_1^{d_1}+\dots+x_n^{d_n}$ with $n\geq2$ and $d_i\geq2$, $R=k[[x_1,\dots,x_n]]/(f)$ and $I=(x_1,\dots,x_{n-1})R$. Then $u=x_n^{d_n-1}$ generates the socle of $R/I$. Let $J=(x_1,\dots,x_{n-1},x_n^{d_n-1})$. Then, for $k$ perfect,
$$\operatorname{FS}_e(R)=d_n\,p^{e(n-1)}-\operatorname{HK}_e(R,J).$$

So the F-signature function of a diagonal hypersurface has the same shape as its Hilbert–Kunz function: for all $e\geq e_0$,
$$\operatorname{FS}_e\left(\frac{\mathbb F_p[[x_1,\dots,x_n]]}{(x_1^{d_1}+\dots+x_n^{d_n})}\right)=c\,p^{(n-1)e}+c_1(e)\,\ell^{\lfloor e/\mu\rfloor},$$
with the same restrictions on $e_0$, $\mu$, $\ell$ and $c_1$ as in [Han and Monsky's theorem](han-monsky-1-shape-of-hilbert-kunz-functions.html). The Han–Monsky algorithm computes it with $\beta=(1/d_1,\dots,1/d_{n-1},(d_n-1)/d_n)$. Moreover $e(R)=\min_id_i$, and $I$ is a minimal reduction of $\mathfrak m$ if and only if $d_n=\min_id_i$. The code puts the variable with the smallest exponent last. By the first formula of the proposition, which holds for any parameter ideal, both choices give the same function.

## An example: $x^3+y^3+z^3$

Let $f=x^3+y^3+z^3\in k[[x,y,z]]$, with $k$ perfect of characteristic $p>0$. By Fedder's criterion, $R=k[[x,y,z]]/(f)$ is F-pure if $p\equiv1\pmod 3$, and it is not if $p\equiv2\pmod3$. In the second case $\operatorname{FS}_e(R)=0$, so let us focus on the first. We will show with the Han–Monsky algorithm that then $\operatorname{FS}_e(R)=1$.

Let $J=(x,y,z^2)$. By the lemma, we only need to apply the Han–Monsky algorithm to the ideal $J$. Let $p\equiv1\pmod3$ and $a=(p-1)/3$. Then we can choose $e_0=0$ and $\mu=1$: with $\beta=(\frac13,\frac13,\frac23)$, the integer part is $r=0$, and $p\beta=(a,a,2a)+\beta$. Thus $z'=z$, $R=(a,a,2a)$ and $\sum R_i=4a\equiv0\equiv\sum r_i\pmod 2$, so the hypotheses of the corollary hold. Since the example is two-dimensional, $\ell\in\{0,1\}$, and
$$\operatorname{HK}_e(R,J)=c\,p^{2e}-\Delta$$
for rational constants $c,\Delta$ and all $e\geq0$. Note that $2=\operatorname{HK}_0(R,J)=c-\Delta$, so $\operatorname{HK}_1(R,J)=cp^2-\Delta=c(p^2-1)+2$, and
$$e_\text{HK}(R,J)=\frac{\operatorname{HK}_1(R,J)-2}{p^2-1}.$$

To compute $\operatorname{HK}_1(R,J)$ in general, we can use the Han–Monsky ring. As $p/3=a+\frac13$ and $2p/3=2a+\frac23$,
$$\operatorname{HK}_1(R,J)=27\,\alpha\big(\delta_{p/3}^2\,\delta_{2p/3}\big)=\alpha\big((2\delta_a+\delta_{a+1})^2(\delta_{2a}+2\delta_{2a+1})\big)=27a^2+18a+2=3p^2-1.$$
Let us check the last two equalities:

```sage
for p in [7, 13, 19, 31]:
    a = (p - 1) // 3
    d = lambda i: delta(i, p)
    print(p, ((2*d(a) + d(a+1))^2 * (d(2*a) + 2*d(2*a+1))).D(), 27*a^2 + 18*a + 2, 3*p^2 - 1)
```

Therefore $e_\text{HK}(R,J)=3$ and $\Delta=1$, so $\operatorname{HK}_e(R,J)=3p^{2e}-1$, and by the lemma $\operatorname{FS}_e(R)=1$ for all $e\geq1$. This is a well-known example of a hypersurface that is F-split but not strongly F-regular.

```sage
for p in [7, 5]:
    S.<x,y,z> = GF(p)[]
    print("p = %d:" % p, FS_function_diagonal(x^3 + y^3 + z^3))
```

Here are the values of $\operatorname{HK}_e(R,J)$ and $\operatorname{FS}_e(R)$ for several primes. The last column is an independent Gröbner basis computation of $\operatorname{FS}_e$, via the colon ideal:

```sage
for p in [7, 13, 5, 11]:
    HKJ = [_hk_value(p, [3,3,3], [1,1,2], e) for e in range(3)]
    print("p = %2d (p mod 3 = %d):  HK_e(R,J) = %s,  FS_e = %s,  Groebner FS_e = %s"
          % (p, p % 3, HKJ, [3*p^(2*e) - HKJ[e] for e in range(3)], [fs_brute(p, [[3],[3],[3]], e) for e in range(3)]))
```

## More examples

**Quotient singularities.** Their F-signature is $1/|G|$ when $p\nmid|G|$ [WY04, HL04]. For $A_n=x^2+y^2+z^{n+1}$ ($|G|=n+1$), $E_6=x^2+y^3+z^4$ ($|G|=24$) and $E_8=x^2+y^3+z^5$ ($|G|=120$):

```sage
p = 7
for name, exps, G in [("A_3", [2,2,4], 4), ("A_5", [2,2,6], 6), ("E_6", [2,3,4], 24), ("E_8", [2,3,5], 120)]:
    print(name, exps, " s =", F_signature_diagonal(p, exps), "  1/|G| =", 1/G)
S.<x,y,z> = GF(p)[]
print(FS_function_diagonal(x^2 + y^3 + z^5))
```

**Comparison with [CSTZ24, Theorem 7.1]**, for $x^3+y^3+z^3+t^3$:

```sage
p = 7
s = F_signature_diagonal(p, [3,3,3,3])
print("s =", s, "  formula of [CSTZ24, Thm 7.1]:", 3*p*(p-1)*(p+1)/(8*(3*p^3-p+2*(-1)^(p%3))))
S.<x,y,z,t> = GF(5)[]
FS_function_diagonal(x^3 + y^3 + z^3 + t^3)
```

## Using the matrix representation

The results above say that the Hilbert–Kunz function is determined by a few of its values. In the example of $x^3+y^3+z^3$ it is recovered from $\operatorname{HK}_0$ and $\operatorname{HK}_1$ alone. But computing $\operatorname{HK}_1$ in a characteristic-free way requires a potentially subtle computation in $\Lambda_1$. This is where the [matrix representation](han-monsky-2-the-han-monsky-ring.html) of $\Lambda_e$ by $p^e\times p^e$ integer matrices is very useful.

**Example** [Yos09, PSSY26]. Let $f=x_1^2+\dots+x_{d+1}^2$. For every $p>2$, the Hilbert–Kunz function is $\operatorname{HK}_e(R)=c\,p^{de}+\Delta_e$ for all $e\geq0$, with $\Delta_{e+1}=\ell\,\Delta_e$, where $\ell=\alpha\big(\lambda_{(p-1)/2}^{d+1}\big)$. Similarly, $\operatorname{HK}_1(R)=\alpha\big((\delta_{(p-1)/2}+\delta_{(p+1)/2})^{d+1}\big)$. So the problem becomes computing the $(1,1)$ entry of the $(d+1)$-th power of the matrices of $\lambda_{(p-1)/2}$ and $\delta_{(p-1)/2}+\delta_{(p+1)/2}$. For instance, for $p=5$ and $d=3$:

```sage
G = HanMonskyRing(5)
L = G.lam(2).matrix()
M = (G.delta(2) + G.delta(3)).matrix()
print(L); print(); print(M); print()
(L^4)[0,0], (M^4)[0,0]   # d = 3: l and HK_1(R)
```

One can show that, to solve this problem, one may as well consider the matrix of $\delta_{(p-1)/2}+\delta_{(p+1)/2}$ without the minus signs. In this case of the $A_1$ singularity, Pak, Shapiro, Smirnov and Yoshida [PSSY26] interpret the problem with Ehrhart theory. They recover the $\sec x+\tan x$ formula of Gessel and Monsky this way, and show that $p\mapsto e_\text{HK}(R_{p,d})$, where $R_{p,d}$ is the coordinate ring of $f$ over $\mathbb F_p$, is a rational function $f(p^2)/g(p^2)$ with $\deg f,\deg g\leq d$.

{% comment %} Turns ```sage code blocks into runnable SageMathCell cells (https://sagecell.sagemath.org). Enabled per page with `sagecell: true`. Cells on a page share one Sage session, like notebook cells. With `sage_preload: /path/to/module.py`, a "Load module.py" button is added before the first cell. The page downloads the file from this site (so it also works in the local preview) and runs it in the session as plain Python, like Sage's load("module.py"). {% endcomment %}
